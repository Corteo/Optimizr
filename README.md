 # Optimizr (optimizr)

Haptic Optimizr est un plugin WordPress qui vous permet d'activer ou de désactiver certaines fonctionnalités et de gérer des options spécifiques à votre site. 
Il permet également la gestion des cookies des différents services tiers et permet d'être en conformité avec le RGPD.

## Description

Ce plugin vous permet de contrôler et de personnaliser diverses fonctionnalités et options de votre site WordPress.
*Liste des fonctionalités :* 
  - I/O les images à la une pour des types de posts spécifique
  - Ajout du support du service Tarteaucitron.js (AmauryC)
      - Liste des services supportés : 
        - Google Analytics 4
        - Google Ads
        - Clarity
        - Matomo
        - Hotjar
        - Facebook
        - Facebook Pixel
        - Google Fonts
        - Google Maps
        - Google reCAPTCHA
        - hCAPTCHA
        - X (Twitter)
        - Dailymotion
        - Youtube


*Langages supportées:*
  - FR

## Installation

1. Dans l'administration de WordPress, allez à "Plugins" > "Ajouter des plugins".
2. Recherchez "Haptic Optimizr" et cliquez sur "Installer maintenant".
3. Une fois l'installation terminée, cliquez sur "Activer".

## Utilisation

Une fois le plugin activé, vous pouvez accéder à la page d'options en allant à "Réglages" > "Haptic - Options" dans le menu de gauche de l'administration WordPress.
